FTC ONLINE — Full Throttle Championship

Versione con calendario gare sincronizzato in tempo reale.

CONTENUTO
- index.html: web-app FTC
- manifest.webmanifest: installazione come app/PWA
- sw.js: service worker
- icon-192.png / icon-512.png: icone FTC
- firebase-config.js: configurazione Firebase
- database.rules.json: regole database

NUOVA FUNZIONE CALENDARIO
- Scheda pubblica “Calendario”
- Mostra data, nome gara, circuito/luogo e ora
- Evidenzia la prossima gara
- Si aggiorna automaticamente per tutti i piloti
- L’Admin può aggiungere e cancellare gare dal pannello Admin

Il progetto è già predisposto per il Firebase configurato per FTC1.
Non condividere password o credenziali Firebase.


CALENDARIO: nel pannello Admin puoi scegliere Stato/Bandiera. La bandiera viene mostrata accanto al nome della gara e il paese sotto il nome.
